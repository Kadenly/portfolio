# Kaden Ly — Portfolio

Personal portfolio site built with React + Vite, deployed on Netlify.

## Stack
- React 19 + React Router
- GSAP (`SplitText`) and `@react-spring/web` for text/scroll animations
- Vite for dev/build

## Structure
- `src/pages/` — Home, Projects, Me
- `src/pages/projectpages/` — one detail page per project (Jukebox, Redbull Can, Splitflap, Robotic Arm, Cheesesteak)
- `src/components/` — Navbar, ProjectCard, BackButton, animation helpers (Spring, SplitText, AnimatedContent)

## Local dev
```
npm install
npm run dev
```
